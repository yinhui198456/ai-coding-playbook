# TCP AI Coding 阶段复盘

## 本阶段一句话

已经从“让 Agent 尽快写出代码”进步到“先确认业务、限制 Agent 权限、再用独立证据证明可用”；但复杂业务仍有过早进入 Coding 的问题。

## 发生过的关键事件

1. **#178 进入实现过早。** 评级保存、提升项、计划月份和任务生成的动作边界在 Coding 后继续变化，造成多轮前向整改。
2. **#178 的测试和真实合同不完全等价。** 独立审查继续发现重复请求、版本更新、真实前端调用和旧接口问题。
3. **#181 验证了更小、更清楚的交付方式。** 范围明确，专项测试、隔离浏览器和真实 Chrome 证据一致，用户一次验收通过。
4. **Agent 协作开始分层。** 规划、单一写入、只读审查和动态状态被放到不同位置，减少权限和上下文混乱。
