# 关于这个知识库

这不是 TCP 项目开发文档，也不是术语收藏册。它只回答：

> 我怎样通过真实项目，更好地使用 AI 完成软件开发？

## 内容原则

- 先图后文字，让非专业开发者 5～10 秒看懂。
- Markdown 是唯一知识源，Quartz 只是展示层。
- 不保存当前提交编号、临时检查状态、端口、凭据或敏感信息。
- 一次踩坑只生成候选经验，不直接升级为 SOP 或 Skill。
- 大厂资料只作外部能力标尺，不编造真实面试题。

## 技术说明

本站使用 [Quartz](https://quartz.jzhao.xyz/) 从 `content/` 下的 Markdown 自动生成。修改知识时只编辑 Markdown，不手工维护生成后的 HTML。
